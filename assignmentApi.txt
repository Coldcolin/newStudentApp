=== ASSIGNMENT MANAGEMENT ENDPOINTS ===

1. CREATE ASSIGNMENT
   Method: POST
   Endpoint: /assignments/create
   Authentication: Not required
   
   Required Fields:
   - week (number, min: 1)
   - title (string)
   - taskDescription (string)
   - stack (enum: "Front End", "Back End", "Product Design")
   - dueDate (string, format: "YYYY-MM-DD")
   - dueTime (string, format: "HH:MM")
   
   Optional Fields:
   - allowLateSubmissions (boolean, default: false)
   
   Example Request:
   POST https://sotw-back-onrender.com/assignments/create
   Content-Type: application/json
   
   {
     "week": 3,
     "title": "React Component Development",
     "taskDescription": "Build a responsive dashboard component using React hooks and styled-components. Include proper state management and error handling.",
     "stack": "Front End",
     "dueDate": "2026-02-15",
     "dueTime": "23:59",
     "allowLateSubmissions": true
   }
   
   Example Response:
   {
     "message": "Assignment created successfully",
     "assignment": {
       "_id": "65f1234567890abcdef12345",
       "week": 3,
       "title": "React Component Development",
       "taskDescription": "Build a responsive dashboard component using React hooks and styled-components. Include proper state management and error handling.",
       "stack": "Front End",
       "dueDateTime": "2026-02-15T23:59:00.000Z",
       "allowLateSubmissions": true,
       "createdAt": "2026-02-08T10:30:00.000Z",
       "updatedAt": "2026-02-08T10:30:00.000Z",
       "formattedDueDate": "15th February 2026 11:59 PM"
     }
   }

5. UPDATE ASSIGNMENT (Dynamic)
   Method: PATCH
   Endpoint: /assignments/:assignmentId
   Authentication: Not required (tutor access)
   
   URL Parameters:
   - assignmentId (string, required)
   
   Optional Fields (only provided fields will be updated):
   - title (string)
   - taskDescription (string)
   - stack (enum: "Front End", "Back End", "Product Design")
   - dueDate (string, format: "YYYY-MM-DD")
   - dueTime (string, format: "HH:MM")
   - allowLateSubmissions (boolean)
   
   Example Request (Update only title):
   PATCH https://sotw-back-onrender.com/assignments/65f1234567890abcdef12345
   Content-Type: application/json
   
   {
     "title": "Advanced React Component Development"
   }
   
   Example Request (Update due date only):
   PATCH https://sotw-back-onrender.com/assignments/65f1234567890abcdef12345

   {
     "dueDate": "2026-02-20"
   }

=== VALIDATION RULES & NOTES ===

Field Validations:
- week: Must be a positive integer (min: 1)
- grade: Must be between 0 and 20 (inclusive)
- stack: Must be exactly one of: "Front End", "Back End", "Product Design"
- submissionLink: Must be a valid URL format
- dueDate: Must be in YYYY-MM-DD format
- dueTime: Must be in HH:MM format (24-hour)

Authentication:
- Student endpoints require JWT token with role: "student"
- Tutor endpoints generally don't require authentication (based on current setup)
- Student stack must match assignment stack for submissions

Business Rules:
- Students can only submit to assignments matching their stack
- Late submissions are only allowed if assignment.allowLateSubmissions = true
- Students can resubmit (updates existing submission)
- Deleting assignment also deletes all related submissions
- Grades can be updated multiple times

Date/Time Handling:
- All dates stored as combined datetime in UTC
- Formatted dates displayed as: "15th February 2026 11:59 PM"
- Late submission calculated by comparing current time with dueDateTime

Error Responses:
- 400: Bad Request (validation errors, missing fields)
- 401: Unauthorized (invalid/missing token)
- 403: Forbidden (role/stack restrictions)
- 404: Not Found (assignment/submission not found)
- 500: Internal Server Error
